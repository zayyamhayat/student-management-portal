# Student Management Portal

A database-driven Student Management Portal developed using PHP, MySQL, HTML and CSS as a university database project.

## Overview

The system provides separate functionality for students and teachers and uses a MySQL database to manage academic information.

## Features

- Student login
- Teacher login
- Role-based access
- Student dashboard
- Course management
- Attendance management
- Marks management
- MySQL database integration
- PHP-based backend

## Technologies

- PHP
- MySQL
- SQL
- HTML
- CSS

## Project Structure

- `auth/` — Authentication and login functionality
- `db/` — Database connection
- `student/` — Student-related functionality
- `teacher/` — Teacher-related functionality
- `sql code.sql` — Database schema and SQL queries

## How to Run

1. Install XAMPP or another PHP/MySQL development environment.
2. Place the project folder inside the web server directory.
3. Start Apache and MySQL.
4. Create/import the database using `sql code.sql`.
5. Update the database connection settings if required.
6. Open the project through the local server.
